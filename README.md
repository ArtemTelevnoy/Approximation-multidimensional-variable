## Цель

Придумать способы аппроксимации многомерных дискретных распределений с
различными свойствами и получить для этих способов оценки информационной
сложности.

## План работы

1.  Рассматривать распределения с разными свойствами. Находить способ аппроксимации и оценку её информационной сложности аналитически. 
2. Проверить выполнимость оценок численно на практике, произведя расчёты на примерах 
3. Если останется время, то попробовать рассмотреть многомерные абсолютно-непрерывные распределения
